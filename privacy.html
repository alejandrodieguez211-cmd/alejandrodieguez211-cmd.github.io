Privacy Policy

Last updated: October 17, 2026

This policy covers the What If Universe uploader, a private tool used only by the owner of the What If Universe YouTube channel to upload and schedule the channel's own videos through the YouTube Data API.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and your data is also subject to the Google Privacy Policy.

What data the tool accesses and collects

With the permission the channel owner grants through Google, the tool accesses only the What If Universe channel: it uploads the channel's own videos, sets their titles, descriptions, tags and publishing times, and reads the channel's statistics (views, subscribers). It does not access any other channel or account, and it does not collect any personal data from viewers or other users.

How the data is used, stored and shared

  • Data is used only to publish and manage the channel's videos and to measure how they perform.
  • The only data stored is a list of the channel's own uploaded videos (video ID, title and date) and the access credential, which is kept as a private environment variable and never published.
  • No data is sold, rented or shared with third parties.
  • The tool does not use cookies and does not store or access any information on users' devices.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. When access is revoked, the stored credential stops working and is deleted, and any stored API data is deleted within 30 days.

Changes

If this policy changes, the updated version will be published on this page with a new date.
